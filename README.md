# Borgen i granskogen

Ett litet medeltida äventyr i 3D som körs direkt i webbläsaren. Hjälp folket i borgen, samla örter i skogen och upptäck tjärnen och den gamla ruinen. Längs vägen lär du dig om livet på medeltiden.

**Spela:** https://petersvardsmyr-cyber.github.io/borgen-i-granskogen/

Fungerar på dator (tangentbord och mus), mobil och surfplatta (pekskärm).

## Tack till

- Musik: RandomMind, via OpenGameArt (CC0)
- Eldljud: PagDev, via OpenGameArt (CC0)
- 3D-grafik med [three.js](https://threejs.org/)
